# Multi-Agent Roguelite Prototype

A lightweight roguelite prototype designed as a learning project for AI-assisted development, multi-agent workflow orchestration, and eventually Salesforce technical architect simulation.

## Project Goal

Build a small but complete roguelite game where multiple AI-style agents help simulate different parts of game behavior, world logic, enemy decisions, balancing, QA feedback, and player progression.

This project is intentionally scoped small so the focus stays on learning how to design, build, test, document, and iterate with AI agents.

## Why This Project Exists

The long-term goal is to build toward a multi-agent educational platform for Salesforce delivery and technical architect enablement.

That future platform would simulate roles like:

- Business Analyst
- Technical Architect
- Security Architect
- QA Engineer
- DevOps Engineer
- Implementation Consultant
- Product Owner

This roguelite is the first practice project to learn the patterns in a lower-risk, more fun environment.

## Core Concept

The player enters procedurally generated rooms, fights enemies, collects upgrades, and survives as long as possible.

Behind the scenes, different agents may eventually help with:

- Enemy behavior
- Room generation
- Difficulty scaling
- Item balancing
- Quest/event generation
- QA testing
- Bug reporting
- Player coaching
- Run summaries

## Initial Scope

The first playable prototype should include:

- A controllable player
- Basic movement
- One enemy type
- Simple combat
- Health and damage
- One room or small arena
- Restartable runs
- Basic upgrade or reward after combat
- Clear documentation of each development step

## Stretch Goals

Future features may include:

- Multiple enemy types
- Procedural rooms

- DevOps-style release notes
- Difficulty modifiers

## Development Philosophy

This project should be built iteratively.

Each major change should include:

1. A clear goal
2. The implementation steps
3. Any issues found
4. The fix or decision made
5. What was learned
6. A commit with a useful message

The point is not just to build a game. The point is to build a documented AI-assisted development workflow.
